# 21 November 2026 in one image

An entry for make.fun's "Sum up 21 November's world news in one image" bounty.

`entry.png` is a 1024×1024 poster naming the day and eight stories reported on 21 November 2026: the Shenzhen peace declaration, the missile barrage on Kyiv, GTA VI's $2.3bn launch week, the US Senate's war-powers vote, the missile incursion into Poland, Cyclone Akvan, the UN children's fund, and the WFP hunger appeal. `main.ts` copies the poster to `/output/entry.png`; the program is deterministic and uses only the Node standard library.
